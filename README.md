# MorseDecoder

Multi-stream Morse code decoder with:
- Live audio input
- FFT waterfall display
- Automatic frequency detection
- Multi-frequency CW decoding
- Custom prosigns/tokens
- Preferences and audio device selection

2. Single-frequency detector

6. Multi-stream decoding
